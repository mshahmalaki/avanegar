## [0.1.0] - 2026-08-13

### Added

- Privacy-first Persian transcription web interface
- Local `faster-whisper` engine with a clearly labeled demo fallback
- Persian text normalization and uncertainty markers
- Timestamped TXT, JSON, SRT, and WebVTT exports
- FastAPI integration API and browser microphone capture
- Python package, command-line entry point, and Docker image
- CI, Pylint, CodeQL, dependency review, PyPI, and GHCR workflows
